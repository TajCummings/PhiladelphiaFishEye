1.docker run --name tacotracker-db \
  -e POSTGRES_USER=<username> \
  -e POSTGRES_PASSWORD=<password> \
  -e POSTGRES_DB=<database_name> \
  -p 5432:5432 \
  -d postgres
2.Terminal: run the following command to verify the container is running
    -docker ps
3.Add the following to your
appsettings.json {
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=<database_name>;Username=<username>;Password=<password>"
  }
}

Running first migration
docker start tacotracker-db

dotnet ef migrations add InitialCreate
dotnet ef database update

//migrations add creates a new Migrations folder in your project with the SQL blueprint
//database update actually runs that SQL against your Postgres database and creates the Guesses table
